## 시작하기

### FinLab에 접속하기

1. 웹 브라우저에서 FinLab URL로 이동합니다
   - 로컬 개발: `http://localhost:5173`
   - 프로덕션: `https://yourusername.github.io/finlab`

2. 랜딩 페이지에서 주요 기능 소개를 확인합니다

3. 우측 상단의 "시작하기" 또는 "로그인" 버튼을 클릭합니다

### 시스템 요구사항

**지원 브라우저**
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

**권장 환경**
- 화면 해상도: 1280×720 이상
- 인터넷 연결: Live 모드 사용 시 필요
- JavaScript: 필수 활성화

## 로그인

### Demo 계정으로 로그인

1. 로그인 페이지에서 이메일 주소 입력
   ```
   demo@finlab.app
   ```

2. "로그인" 버튼 클릭

3. 자동으로 대시보드로 이동

**참고**: Mock 모드에서는 별도의 비밀번호가 필요하지 않습니다. 이메일만 입력하면 JWT 토큰이 자동 발급됩니다.

### 사용자 역할

- **USER**: 일반 사용자, 자신의 포트폴리오만 관리
- **ADMIN**: 관리자, 시드 데이터 및 설정 접근 가능

## 포트폴리오 관리

### 새 포트폴리오 만들기

1. 대시보드에서 "새 포트폴리오" 버튼 클릭

2. 포트폴리오 정보 입력
   - **이름**: 포트폴리오를 식별할 이름 (예: "Tech 포트폴리오")
   - **기준 통화**: USD, KRW, EUR 등 선택

3. "생성" 버튼 클릭

4. 생성된 포트폴리오가 목록에 표시됩니다

### 포트폴리오 보기

**포트폴리오 목록**
- 좌측 사이드바 또는 대시보드에서 모든 포트폴리오 확인
- 각 카드에는 다음 정보가 표시됩니다:
  - 포트폴리오 이름
  - 총 가치
  - 일일 손익
  - 수익률

**상세 정보**
1. 포트폴리오 카드 클릭
2. 다음 정보 확인:
   - 전체 보유 종목
   - 거래 내역
   - 성과 차트
   - 리스크 지표

### 포트폴리오 수정

1. 포트폴리오 상세 페이지에서 "수정" 버튼 클릭
2. 이름 또는 기준 통화 변경
3. "저장" 버튼 클릭

### 포트폴리오 삭제

1. 포트폴리오 상세 페이지에서 "삭제" 버튼 클릭
2. 확인 다이얼로그에서 "확인" 선택
3. 포트폴리오와 관련된 모든 데이터가 삭제됩니다

**주의**: 삭제된 데이터는 복구할 수 없습니다.

## 거래 추적

### 수동으로 거래 추가

1. "거래" 페이지로 이동

2. "거래 추가" 버튼 클릭

3. 거래 정보 입력

**매수 거래 (BUY)**
- 포트폴리오 선택
- 거래 유형: "매수"
- 종목 심볼: AAPL, GOOGL 등
- 수량: 주식 수
- 가격: 주당 가격
- 수수료: 거래 수수료 (선택사항)
- 날짜/시간: 거래 일시
- 메모: 추가 설명 (선택사항)

**매도 거래 (SELL)**
- 매수와 동일한 정보 입력
- 보유 수량보다 많이 매도할 수 없습니다

**입금 (DEPOSIT)**
- 포트폴리오에 현금 추가
- 종목, 수량, 가격 필요 없음
- 금액은 메모에 기록

**출금 (WITHDRAW)**
- 포트폴리오에서 현금 인출
- 입금과 동일한 방식

4. "저장" 버튼 클릭

### CSV 파일로 일괄 추가

1. "거래" 페이지에서 "CSV 가져오기" 버튼 클릭

2. CSV 파일 선택 또는 드래그 앤 드롭

**CSV 파일 형식**
```csv
type,symbol,qty,price,fee,timestamp,note
BUY,AAPL,10,150.00,0.99,2025-10-01T14:30:00Z,Initial purchase
BUY,GOOGL,5,140.00,0.99,2025-10-02T14:30:00Z,
DEPOSIT,,,,,2025-10-01T10:00:00Z,Initial funding
```

**필수 필드**
- `type`: BUY, SELL, DEPOSIT, WITHDRAW
- `timestamp`: ISO 8601 형식

**선택 필드**
- `symbol`: 종목 심볼 (BUY/SELL은 필수)
- `qty`: 수량 (BUY/SELL은 필수)
- `price`: 가격 (BUY/SELL은 필수)
- `fee`: 수수료 (기본값: 0)
- `note`: 메모

3. "업로드" 버튼 클릭

4. 처리 결과 확인
   - 성공: X건
   - 실패: X건 (에러 메시지 표시)

### 거래 내역 필터링

**필터 옵션**
- 날짜 범위: 시작일 ~ 종료일
- 거래 유형: BUY, SELL, DEPOSIT, WITHDRAW
- 종목: 특정 심볼

**검색**
- 메모 내용으로 검색

**정렬**
- 날짜순 (최신순/오래된순)
- 금액순 (높은순/낮은순)

### 거래 수정 및 삭제

**수정**
1. 거래 행 클릭
2. 정보 수정
3. "저장" 버튼 클릭

**삭제**
1. 거래 행의 "삭제" 아이콘 클릭
2. 확인 다이얼로그에서 "확인" 선택

**주의**: 거래를 삭제하면 보유 종목 및 손익 계산에 영향을 줍니다.

## 보유 종목 확인

### 현재 보유 종목 보기

1. "대시보드" 또는 포트폴리오 상세 페이지로 이동

2. "보유 종목" 섹션에서 다음 정보 확인:
   - **종목 심볼**
   - **보유 수량**
   - **평균 단가**: FIFO 방식으로 계산
   - **현재 가치**: 보유 수량 × 현재 시세
   - **미실현 손익**: (현재 시세 - 평균 단가) × 보유 수량
   - **수익률**: 미실현 손익 / (평균 단가 × 보유 수량)

### FIFO 계산 방식 이해하기

**First In First Out (선입선출)**

매수 거래:
```
2025-10-01: AAPL 10주 @ $150
2025-10-05: AAPL 5주 @ $155
```

평균 단가 계산:
```
(10 × $150 + 5 × $155) / 15 = $151.67
```

매도 시:
```
2025-10-10: AAPL 8주 @ $160 매도
→ 가장 오래된 10주 중 8주가 먼저 소진됨
→ 실현 손익: (160 - 150) × 8 = $80
→ 남은 보유: 2주 @ $150, 5주 @ $155
```

### 차트로 확인

**포트폴리오 가치 차트**
- 시간에 따른 총 가치 변화
- 일별, 주별, 월별, 연별 보기

**종목별 비중 차트**
- 파이 차트로 각 종목의 비중 확인
- 섹터별 분산 투자 현황 파악

## 백테스팅

### DCA (Dollar Cost Averaging) 전략 테스트

1. "백테스트" 페이지로 이동

2. 백테스트 설정
   - **종목**: 테스트할 종목 심볼 (예: SPY, AAPL)
   - **시작일**: 백테스트 시작 날짜
   - **종료일**: 백테스트 종료 날짜
   - **투자 금액**: 매 주기마다 투자할 금액
   - **투자 주기**: 주간 또는 월간

**예시 설정**
```
종목: SPY (S&P 500 ETF)
시작일: 2020-01-01
종료일: 2025-10-03
투자 금액: $1,000
투자 주기: 월간
```

3. "백테스트 실행" 버튼 클릭

4. Web Worker가 백그라운드에서 계산 시작
   - 진행 상황 표시
   - 10,000+ 캔들 데이터도 빠르게 처리

### 결과 분석

**성과 지표**
- **최종 가치**: 백테스트 종료 시점의 총 가치
- **투자 원금**: 실제 투입한 총 금액
- **수익률**: (최종 가치 - 투자 원금) / 투자 원금
- **CAGR**: 연평균 복리 수익률
- **샤프 비율**: 위험 대비 수익률 (높을수록 좋음)
- **최대 낙폭**: 최고점 대비 최대 하락률

**비교 시나리오**
- **DCA**: 정액 적립식 투자
- **Lump Sum**: 시작일에 전액 일시 투자

**차트**
- 누적 투자 가치 그래프
- DCA vs Lump Sum 비교
- 낙폭 시각화

### 백테스트 결과 저장

1. 결과 페이지에서 "저장" 버튼 클릭
2. 이름 입력 (예: "SPY 5년 월 100만원")
3. 저장된 백테스트는 목록에서 다시 확인 가능

## 목표 및 계획

### 재무 목표 설정

1. "목표 & 계획" 페이지로 이동

2. "새 목표" 버튼 클릭

3. 목표 정보 입력
   - **목표 이름**: 은퇴 자금, 비상금 등
   - **목표 금액**: 달성하고자 하는 금액
   - **목표 날짜**: 달성 목표 일자
   - **현재 금액**: 현재까지 모은 금액

**예시**
```
이름: 은퇴 자금
목표 금액: $1,000,000
목표 날짜: 2045-12-31
현재 금액: $50,000
```

4. "생성" 버튼 클릭

5. 진행률 추적
   - 진행률 바로 시각화
   - 달성까지 필요한 금액
   - 목표 날짜까지 남은 기간

### DCA 투자 계획 만들기

1. "새 계획" 버튼 클릭

2. 계획 정보 입력
   - **종목**: 정기적으로 매수할 종목
   - **투자 금액**: 매 주기마다 투자할 금액
   - **투자 주기**: 주간 또는 월간
   - **시작일**: 계획 시작 날짜
   - **종료일**: 계획 종료 날짜 (선택사항)

**예시**
```
종목: VTI (Total Stock Market ETF)
투자 금액: $500
투자 주기: 월간
시작일: 2025-11-01
종료일: 2030-12-31
```

3. "생성" 버튼 클릭

4. 계획 활성화/비활성화
   - 토글 스위치로 계획 일시 정지 가능
   - 비활성화해도 데이터는 유지됨

### 계획 실행 시뮬레이션

1. 계획 카드에서 "시뮬레이션" 버튼 클릭

2. 과거 데이터 기반 예상 결과 확인
   - 5년 후 예상 가치
   - 예상 수익률
   - 투자 원금 대비 증가율

3. 시나리오 조정
   - 투자 금액 변경
   - 투자 주기 변경
   - 즉시 결과 업데이트

## API 플레이그라운드

### Swagger UI 사용하기

1. "API 플레이그라운드" 페이지로 이동

2. OpenAPI 스펙 자동 로드

3. Endpoint 탐색
   - 왼쪽 사이드바에서 카테고리 선택
   - 각 엔드포인트의 상세 정보 확인

### API 요청 테스트

**인증 설정**
1. 우측 상단 "Authorize" 버튼 클릭
2. Bearer Token 입력
   ```
   로그인 후 받은 JWT 토큰 복사/붙여넣기
   ```
3. "Authorize" 버튼 클릭

**요청 보내기**
1. 테스트할 엔드포인트 선택 (예: `GET /v1/portfolios`)
2. "Try it out" 버튼 클릭
3. 필요한 파라미터 입력
4. "Execute" 버튼 클릭
5. 응답 확인
   - 상태 코드
   - 응답 헤더
   - 응답 본문

**예시: 새 포트폴리오 생성**
```
Endpoint: POST /v1/portfolios

Request Body:
{
  "name": "Tech Portfolio",
  "baseCurrency": "USD"
}

Response:
{
  "id": 2,
  "userId": 1,
  "name": "Tech Portfolio",
  "baseCurrency": "USD",
  "createdAt": "2025-10-03T12:00:00Z",
  "updatedAt": "2025-10-03T12:00:00Z"
}
```

### Mock 모드 vs Live 모드

**설정 페이지에서 전환**
1. 우측 상단 설정 아이콘 클릭
2. "Backend 모드" 섹션
   - **Mock**: 브라우저 IndexedDB 사용 (오프라인)
   - **Live**: 실제 Backend API 호출 (온라인)
3. Live 모드 선택 시 Backend URL 입력
   ```
   https://api.finlab.app
   ```
4. "저장" 버튼 클릭

**차이점**
- Mock: 즉시 응답, 네트워크 불필요, 데이터는 로컬에만 저장
- Live: 실제 HTTP 요청, 서버 필요, 데이터 동기화 가능

## 일반 팁

### 데이터 백업

Mock 모드에서는 브라우저 IndexedDB에 데이터가 저장됩니다.

**백업 방법**
1. 브라우저 개발자 도구 (F12) 열기
2. Application 탭 → IndexedDB → FinLabDB
3. 각 테이블 Export (브라우저 기능 활용)

**주의**: 브라우저 캐시를 지우면 데이터가 삭제될 수 있습니다.

### 키보드 단축키

- `Ctrl/Cmd + K`: 검색
- `Ctrl/Cmd + N`: 새 포트폴리오
- `Ctrl/Cmd + T`: 새 거래
- `Esc`: 다이얼로그 닫기

### 성능 최적화

**대량 데이터 처리**
- CSV 임포트 시 Web Worker 사용으로 UI 블로킹 없음
- 백테스트 계산도 백그라운드에서 수행

**차트 렌더링**
- 데이터 포인트가 많을 경우 자동으로 샘플링
- 줌/팬 기능으로 상세 분석 가능

### 접근성

**스크린 리더 지원**
- ARIA 라벨 적용
- 키보드 네비게이션 완전 지원

**고대비 모드**
- 색상 대비 WCAG AA 준수
- 브라우저 설정에 따라 자동 조정

## 자주 묻는 질문

**Q: 데이터가 안전한가요?**
A: Mock 모드에서는 모든 데이터가 브라우저에만 저장됩니다. 서버로 전송되지 않습니다.

**Q: 실제 시세를 사용하나요?**
A: 데모용 CSV 파일을 사용합니다. Live 모드에서는 실제 시세 API 연동 가능합니다.

**Q: 모바일에서 사용할 수 있나요?**
A: 반응형 디자인으로 모바일에서 작동하지만, 최적의 경험은 데스크톱에서 제공됩니다.

**Q: 백테스트 결과를 신뢰할 수 있나요?**
A: 과거 데이터 기반 시뮬레이션이며, 실제 투자 결과를 보장하지 않습니다.

**Q: 여러 포트폴리오를 동시에 관리할 수 있나요?**
A: 네, 제한 없이 여러 포트폴리오를 생성하고 관리할 수 있습니다.
